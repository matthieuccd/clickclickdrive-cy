## Μπορείτε να οδηγείτε με ευρωπαϊκή άδεια στην Κύπρο;

Ναι, μπορείτε. Κάτοχοι άδειας οδήγησης από χώρα της ΕΕ ή του ΕΟΧ μπορούν να οδηγούν νόμιμα στην Κύπρο. Δεν χρειάζεστε νέα εξέταση. Δεν χρειάζεστε νέο μάθημα.

Η Κύπρος αναγνωρίζει πλήρως τις άδειες που εκδίδονται από άλλες χώρες της ΕΕ. Αυτό σημαίνει ότι, αν μετακομίσατε από τη Γερμανία, την Ελλάδα ή την Ολλανδία, η άδειά σας παραμένει έγκυρη. Δεν υπάρχει κάποιος νόμος που σας υποχρεώνει να κάνετε ανταλλαγή αμέσως.

Αυτό ισχύει για μόνιμους κατοίκους, όχι μόνο για τουρίστες. Ακόμα και αν ζείτε χρόνια στην Κύπρο, μπορείτε να κρατάτε την άδεια της χώρας προέλευσής σας. Η αστυνομία και οι άλλες αρχές οφείλουν να την αναγνωρίζουν.

Βέβαια, η άδεια πρέπει να είναι σε ισχύ. Αν έχει λήξει, τα πράγματα αλλάζουν. Για αυτό θα μιλήσουμε σε επόμενη ενότητα.

Αξίζει να ξέρετε ότι το σύστημα αυτό είναι αμοιβαίο. Η κυπριακή άδεια ισχύει σε όλες τις χώρες της ΕΕ. Έτσι, αν κάποτε μετακομίσετε αλλού, δεν χρειάζεται να αρχίσετε από την αρχή.

Για πολίτες που δεν είναι από την ΕΕ, τα πράγματα είναι διαφορετικά. Αν έχετε βρετανική άδεια μετά το Brexit, διαβάστε πληροφορίες για το [βρετανικό δίπλωμα στην Κύπρο](/arthra/vretaniko-diploma-kypros). Αν έρχεστε από χώρα εκτός ΕΕ, δείτε τον οδηγό για [δίπλωμα για ξένους στην Κύπρο](/arthra/diploma-odigisis-gia-ksenous-stin-kypro).

Για τους Ευρωπαίους πολίτες, λοιπόν, η απάντηση είναι απλή: η άδειά σας ισχύει. Το ερώτημα δεν είναι αν μπορείτε να οδηγείτε. Το ερώτημα είναι αν σας συμφέρει να κάνετε ανταλλαγή.

Και για αυτό, η απάντηση εξαρτάται από τη ζωή σας στην Κύπρο. Αν μείνετε για λίγους μήνες, πιθανώς δεν αξίζει η ταλαιπωρία. Αν σκοπεύετε να μείνετε χρόνια, η ανταλλαγή έχει πολλά πλεονεκτήματα που θα δείτε παρακάτω.

## Γιατί οι περισσότεροι κάτοικοι ΕΕ επιλέγουν ανταλλαγή;

Η ανταλλαγή δεν είναι υποχρεωτική, αλλά έχει σοβαρά πλεονεκτήματα. Όσοι μένουν μόνιμα στην Κύπρο συνήθως το κάνουν νωρίς ή αργά.

Οι κυριότεροι λόγοι είναι:

- **Ενοικίαση αυτοκινήτου:** Πολλές εταιρείες ενοικίασης στην Κύπρο προτιμούν κυπριακή άδεια. Με ξένη άδεια μπορεί να χρειαστείτε έξτρα έγγραφα ή να αντιμετωπίσετε καθυστερήσεις.
- **Γραφειοκρατία:** Σε δημόσιες υπηρεσίες, τράπεζες και ασφαλιστικές, η κυπριακή άδεια γίνεται αποδεκτή χωρίς ερωτήσεις.
- **Αντικατάσταση σε περίπτωση απώλειας:** Αν χάσετε την κυπριακή άδεια, την κόβετε εδώ. Αν χάσετε την ξένη άδεια, πρέπει να επικοινωνήσετε με τη χώρα έκδοσης. Αυτό μπορεί να πάρει πολύ χρόνο.
- **Απλότητα στην καθημερινή ζωή:** Λιγότερες εξηγήσεις, λιγότερες ταλαιπωρίες.

Υπάρχει και ένας ακόμα λόγος. Αν περάσουν χρόνια και η άδειά σας λήξει, η διαδικασία ανταλλαγής γίνεται πιο δύσκολη. Μπορεί να χρειαστείτε εξετάσεις. Γι' αυτό, όσοι σχεδιάζουν να μείνουν, κάνουν την ανταλλαγή ενώ η άδειά τους ισχύει ακόμα.

Η κυπριακή άδεια ισχύει σε όλες τις χώρες της ΕΕ. Αν ταξιδέψετε ή μετακομίσετε αργότερα, δεν χάνετε τίποτα. Παραμένετε πλήρως νόμιμοι οδηγοί σε κάθε ευρωπαϊκή χώρα.

Πολλοί Ευρωπαίοι που εγκαθίστανται στην Κύπρο ξεκινούν να ψάχνουν πληροφορίες για τον [πλήρη οδηγό για δίπλωμα οδήγησης στην Κύπρο](/arthra/pws-na-vgaleis-diploma-odigisis-stin-kypro). Εκεί μπορείτε να δείτε το σύνολο του συστήματος αδειών, ακόμα και αν εσείς δεν χρειάζεστε εξετάσεις.

Να θυμάστε: η ανταλλαγή δεν κοστίζει πολύ χρόνο. Η διαδικασία είναι σχετικά απλή. Και μια φορά που το κάνετε, δεν χρειάζεται να ασχοληθείτε ξανά για χρόνια.

## Ποια είναι η διαδικασία ανταλλαγής βήμα προς βήμα;

Η διαδικασία γίνεται στο Τμήμα Οδικών Μεταφορών. Δεν χρειάζεστε εξετάσεις. Δεν χρειάζεστε σχολή οδηγών. Χρειάζεστε μόνο τα σωστά έγγραφα και λίγο χρόνο.

Τα βήματα είναι:

1. **Μαζέψτε τα έγγραφα.** Δείτε την επόμενη ενότητα για την πλήρη λίστα. Βεβαιωθείτε ότι όλα είναι έγκυρα και ενημερωμένα.
2. **Επισκεφθείτε γραφείο του Τμήματος.** Μπορείτε να πάτε σε Λευκωσία, Λεμεσό, Λάρνακα, Πάφο ή Παραλίμνι. Διαλέξτε το πιο κοντινό στον τόπο κατοικίας σας.
3. **Συμπληρώστε την αίτηση.** Η φόρμα διατίθεται στο Τμήμα. Μπορείτε να τη ζητήσετε επί τόπου ή να ελέγξετε αν υπάρχει διαθέσιμη διαδικτυακά.
4. **Καταθέστε τα έγγραφα στην υπάλληλο.** Θα ελέγξουν τα πάντα επί τόπου. Αν κάτι λείπει, θα σας πουν αμέσως.
5. **Πληρώστε τα τέλη.** Η τιμή μπορεί να αλλάξει. Ελέγξτε την τρέχουσα χρέωση στο Τμήμα Οδικών Μεταφορών πριν πάτε.
6. **Παραλάβετε την κυπριακή άδεια.** Συνήθως δεν γίνεται αυθημερόν. Ρωτήστε πόσο χρόνο χρειάζεται κατά την κατάθεση.

Η διαδικασία δεν έχει τεχνικές δυσκολίες. Το μόνο που μπορεί να σας καθυστερήσει είναι αν λείπει κάποιο έγγραφο. Γι' αυτό, ελέγξτε τη λίστα δύο φορές πριν πάτε.

Αν δεν μιλάτε ελληνικά καλά, μπορείτε να πάρετε μαζί σας κάποιον που μιλά. Οι υπάλληλοι σε πολλά γραφεία μιλούν αγγλικά, αλλά δεν είναι εγγυημένο.

Δεν υπάρχει ραντεβού σε όλα τα γραφεία. Μερικές φορές χρειάζεται να περιμένετε. Προτιμήστε να πάτε νωρί το πρωί για να αποφύγετε πολυκοσμία.

Αν θέλετε να μάθετε περισσότερα για το σύστημα αδειών στην Κύπρο, ο [πλήρης οδηγός για δίπλωμα οδήγησης](/arthra/pws-na-vgaleis-diploma-odigisis-stin-kypro) εξηγεί όλα τα στάδια από την αρχή.

## Ποια έγγραφα χρειάζεστε για την ανταλλαγή;

Πριν πάτε στο Τμήμα Οδικών Μεταφορών, μαζέψτε όλα τα παρακάτω. Αν λείπει έστω και ένα, η αίτησή σας δεν θα γίνει δεκτή.

Τα έγγραφα που χρειάζεστε:

- **Η ισχύουσα άδεια οδήγησης ΕΕ (πρωτότυπο).** Όχι φωτοτυπία. Το ίδιο το πλαστικό έγγραφο. Πρέπει να είναι σε ισχύ.
- **Απόδειξη κατοικίας στην Κύπρο.** Το «κίτρινο χαρτί» (yellow slip) που εκδίδεται για πολίτες ΕΕ, ή άλλο ισοδύναμο έγγραφο. Αυτό αποδεικνύει ότι είστε νόμιμος κάτοικος Κύπρου.
- **Πρόσφατη φωτογραφία διαβατηρίου.** Μία, τυπικού μεγέθους. Να είναι πρόσφατη, όχι παλιά.
- **Συμπληρωμένη φόρμα αίτησης.** Την παίρνετε από το Τμήμα ή μπορεί να υπάρχει διαθέσιμη στο διαδίκτυο.

Μερικές φορές χρειάζονται και έξτρα έγγραφα, ανάλογα με την περίπτωση. Για παράδειγμα, αν η άδειά σας είναι παλιά ή εκδόθηκε χωρίς ημερομηνία λήξης, μπορεί να ζητηθούν περισσότερα. Ρωτήστε στο Τμήμα αν έχετε αμφιβολία.

Το yellow slip είναι το πιο σύνηθες έγγραφο κατοικίας για πολίτες ΕΕ. Το εκδίδει το Τμήμα Αρχείου Πληθυσμού και Μετανάστευσης. Αν δεν το έχετε ακόμα, κανονίστε το πρώτα.

Μια πρακτική συμβουλή: πάρτε μαζί σας και φωτοτυπίες όλων των εγγράφων. Μερικές φορές το Τμήμα κρατά αντίγραφο. Καλό είναι να έχετε έτοιμες.

Το κόστος της ανταλλαγής δεν είναι σταθερό. Ελέγξτε πάντα την τρέχουσα τιμή απευθείας στο Τμήμα Οδικών Μεταφορών. Δεν αναφέρουμε συγκεκριμένο ποσό γιατί μπορεί να έχει αλλάξει.

## Τι γίνεται με την παλιά σας άδεια;

Αυτό είναι κάτι που πολλοί δεν γνωρίζουν. Όταν κάνετε ανταλλαγή, δεν κρατάτε και τις δύο άδειες.

Η παλιά σας άδεια, αυτή που εκδόθηκε από τη χώρα σας, επιστρέφεται πίσω στη χώρα έκδοσης. Το Τμήμα Οδικών Μεταφορών της Κύπρου την αποστέλλει στις αρχές της χώρας από την οποία εκδόθηκε. Δεν μπορείτε να έχετε ταυτόχρονα κυπριακή και τη χώρα προέλευσης.

Αυτός είναι ένας κανόνας που ισχύει σε όλη την ΕΕ. Κάθε οδηγός επιτρέπεται να έχει μόνο μία ισχύουσα άδεια. Η αρχή που εκδίδει τη νέα άδεια ενημερώνει την αρχή που εξέδωσε την παλιά.

Αυτό σημαίνει ότι δεν μπορείτε να «ξαναπάρετε» την παλιά άδεια αν αλλάξετε γνώμη. Αν αργότερα θελήσετε να αλλάξετε τη χώρα κατοικίας σας, θα χρειαστεί να κάνετε ανταλλαγή εκ νέου στη νέα χώρα.

Για αυτόν ακριβώς τον λόγο, μερικοί άνθρωποι διστάζουν να κάνουν ανταλλαγή. Φοβούνται ότι «χάνουν» κάτι. Στην πράξη, όμως, δεν χάνετε τίποτα. Η κυπριακή άδεια ισχύει παντού στην ΕΕ, όπως ακριβώς και η παλιά σας.

Αν έχετε ειδική κατηγορία άδειας στη χώρα σας, φροντίστε να το αναφέρετε στο Τμήμα. Θέλετε να βεβαιωθείτε ότι η κυπριακή άδεια θα περιλαμβάνει τις ίδιες κατηγορίες οχημάτων.

Πρακτικές συμβουλές για αυτό το στάδιο:

- Φωτογραφίστε την παλιά άδεια πριν την παραδώσετε.
- Κρατήστε κάθε απόδειξη που σας δίνει το Τμήμα.
- Ρωτήστε αν θα σας δοθεί κάποιο προσωρινό έγγραφο ενόσω περιμένετε την κυπριακή άδεια.

## Η προθεσμία και τι συμβαίνει αν τη χάσετε;

Υπάρχει μια χρονική περίοδος μετά την εγκατάστασή σας στην Κύπρο, κατά την οποία μπορείτε να κάνετε ανταλλαγή χωρίς εξετάσεις. Αυτή η περίοδος μπορεί να αλλάξει. Επιβεβαιώστε πάντα την τρέχουσα προθεσμία με το Τμήμα Οδικών Μεταφορών.

Γιατί έχει σημασία αυτό; Γιατί αν αφήσετε να περάσει η προθεσμία, η κατάσταση μπορεί να γίνει πιο περίπλοκη. Σε ορισμένες περιπτώσεις, μπορεί να σας ζητηθεί να κάνετε εξετάσεις. Αυτό σημαίνει χρόνο, κόπο και ίσως επίσκεψη σε σχολή οδηγών.

Τι πρέπει να κάνετε αν ανησυχείτε:

Τι σημαίνει αυτό στην πράξη:

- Μπορεί να χρειαστείτε θεωρητική εξέταση.
- Μπορεί να χρειαστείτε και πρακτική εξέταση.
- Η διαδικασία γίνεται σαν να παίρνετε δίπλωμα για πρώτη φορά.

Υπάρχει όμως και η περίπτωση των αδειών χωρίς ημερομηνία λήξης. Ορισμένες χώρες εξέδιδαν παλαιότερα άδειες χωρίς λήξη, δηλαδή «ισόβιες». Αυτές αντιμετωπίζονται με ειδικό τρόπο στην Κύπρο. Το Τμήμα Οδικών Μεταφορών έχει ξεχωριστές οδηγίες για αυτές. Αν έχετε τέτοια άδεια, επικοινωνήστε απευθείας με το Τμήμα πριν κάνετε οποιαδήποτε ενέργεια.

Αν η άδειά σας έχει λήξει και πρέπει να ξεκινήσετε από την αρχή, μην ανησυχείτε. Υπάρχουν σχολές σε κάθε πόλη που μπορούν να σας βοηθήσουν. Ο [οδηγός για δίπλωμα για ξένους στην Κύπρο](/arthra/diploma-odigisis-gia-ksenous-stin-kypro) εξηγεί τι περιμένει τους νέους οδηγούς στο σύστημα.

Η πιο σοφή κίνηση είναι να ελέγξετε την ημερομηνία λήξης της άδειάς σας σήμερα. Αν πλησιάζει, δράστε άμεσα. Μην αφήνετε να λήξει ενώ ακόμα σκέφτεστε τι να κάνετε.

Ενώ οδηγείτε στην Κύπρο με ληγμένη άδεια, είστε παράνομοι. Αυτό μπορεί να έχει συνέπειες σε ατύχημα, σε έλεγχο από αστυνομία ή σε ασφαλιστική αποζημίωση.

Συνοψίζοντας για αυτή την κατηγορία:

- Ληγμένη άδεια: πιθανές εξετάσεις, επικοινωνήστε με το Τμήμα.
- Άδεια χωρίς λήξη: ειδικοί κανόνες, ρωτήστε το Τμήμα απευθείας.

Η ανταλλαγή ευρωπαϊκής άδειας στην Κύπρο είναι μια από τις πιο απλές διαδικασίες που θα κάνετε ως νέος κάτοικος. Δεν χρειάζεστε εξετάσεις, δεν χρειάζεστε σχολή, και η διαδικασία ολοκληρώνεται σε λίγες επισκέψεις. Αρκεί να έχετε τα σωστά έγγραφα και να μην αφήνετε την άδειά σας να λήξει πριν κάνετε την αίτηση. Αν έχετε οποιαδήποτε αμφιβολία, επικοινωνήστε πρώτα με το Τμήμα Οδικών Μεταφορών και ρωτήστε για την τρέχουσα προθεσμία και τις απαιτήσεις.

**Χρειάζομαι εξέταση για να ανταλλάξω την ευρωπαϊκή μου άδεια με κυπριακή;**
Όχι, δεν χρειάζεστε εξέταση, εφόσον η άδειά σας είναι ισχύουσα και κάνετε την αίτηση εντός της προβλεπόμενης περιόδου. Αν η άδεια έχει λήξει ή αν έχει παρέλθει η προθεσμία, η κατάσταση μπορεί να αλλάξει.

**Μπορώ να κρατήσω και τις δύο άδειες, κυπριακή και της χώρας μου;**
Όχι. Όταν εκδοθεί η κυπριακή άδεια, η παλιά σας επιστρέφεται στη χώρα έκδοσης. Δεν επιτρέπεται να έχετε δύο ισχύουσες άδειες ταυτόχρονα.

**Πού μπορώ να κάνω την ανταλλαγή;**
Μπορείτε να πάτε σε οποιοδήποτε γραφείο του Τμήματος Οδικών Μεταφορών. Υπάρχουν γραφεία σε Λευκωσία, Λεμεσό, Λάρνακα, Πάφο και Παραλίμνι. Διαλέξτε αυτό που βρίσκεται πιο κοντά στον τόπο κατοικίας σας.

**Τι γίνεται αν η χώρα μου εκδίδει άδειες χωρίς ημερομηνία λήξης;**
Αυτές οι «ισόβιες» άδειες αντιμετωπίζονται με ειδικό τρόπο από το Τμήμα Οδικών Μεταφορών. Δεν υπάρχει μία ενιαία απάντηση για όλες τις περιπτώσεις. Επικοινωνήστε απευθείας με το Τμήμα για να μάθετε τι ισχύει για τη δική σας άδεια.
