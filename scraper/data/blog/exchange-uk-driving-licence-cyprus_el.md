## Τι άλλαξε μετά το Brexit για τους κατόχους βρετανικής άδειας στην Κύπρο;

![Βρετανική άδεια οδήγησης πάνω σε τραπέζι, UK driving licence exchange](/blog/exchange-uk-driving-licence-cyprus/inline-1.jpg)
*Η βρετανική άδεια οδήγησης δεν έχει πλέον αυτόματη αναγνώριση στην ΕΕ μετά το Brexit, via Pexels.com*

Πριν το Brexit, η Βρετανία ήταν μέλος της ΕΕ. Αυτό σήμαινε ότι μια βρετανική άδεια οδήγησης αναγνωριζόταν αυτόματα σε όλη την Ευρώπη. Ένας Βρετανός μπορούσε να ζει στην Κύπρο και να οδηγεί με την άδειά του χωρίς κανένα πρόβλημα. Μπορούσε ακόμα να την ανταλλάξει εύκολα με κυπριακή, μέσω του κοινοτικού συστήματος αμοιβαίας αναγνώρισης.

Από την 1η Ιανουαρίου 2021, αυτό άλλαξε. Η Βρετανία βγήκε από την ΕΕ. Η βρετανική άδεια δεν θεωρείται πλέον ευρωπαϊκή. Δεν μπορεί να ανταλλαχτεί με την απλή διαδικασία που ισχύει για άδειες από χώρες της ΕΕ. Αν θέλετε να δείτε πώς λειτουργεί η ανταλλαγή για πολίτες της ΕΕ, μπορείτε να διαβάσετε περισσότερα για την [ανταλλαγή ευρωπαϊκής άδειας στην Κύπρο](/arthra/anallagi-adeias-ee-kypros).

Τι σημαίνει αυτό στην πράξη; Σημαίνει ότι η Κύπρος πλέον χειρίζεται κάθε αίτηση ξεχωριστά. Το Τμήμα Οδικών Μεταφορών εξετάζει κάθε περίπτωση μόνη της. Αυτό δίνει ευελιξία, αλλά δημιουργεί και αβεβαιότητα. Δεν υπάρχει μία αυτόματη απάντηση για όλους.

Η Κυπριακή Δημοκρατία αναγνωρίζει τη Βρετανία ως χώρα της οποίας οι άδειες μπορούν να ανταλλαχτούν. Αυτό είναι καλό νέο. Δεν χρειάζεται κανείς να αρχίσει εκ νέου τη διαδικασία απόκτησης διπλώματος από το μηδέν. Ωστόσο, η ανταλλαγή δεν είναι αυτόματη και απαιτεί συγκεκριμένα έγγραφα.

Πολλοί Βρετανοί στην Κύπρο δεν γνωρίζουν ότι ο χρόνος άφιξής τους στο νησί παίζει ρόλο. Όσοι ήταν ήδη κάτοικοι στην Κύπρο πριν από τις 31 Δεκεμβρίου 2020 ενδέχεται να έχουν διαφορετικά δικαιώματα. Για αυτούς, η μεταβατική περίοδος του Brexit μπορεί να τους δίνει κάποια πλεονεκτήματα. Ωστόσο, πρέπει να επαληθεύσετε την τρέχουσα κατάσταση απευθείας με το ΤΟΜ, γιατί οι κανόνες μπορεί να έχουν αλλάξει.

Αξίζει να θυμάστε ότι η Κύπρος οδηγεί στα αριστερά, όπως και η Βρετανία. Αυτό κάνει την πρακτική πλευρά πιο εύκολη για τους Βρετανούς οδηγούς. Δεν χρειάζεται να συνηθίσουν διαφορετική πλευρά του δρόμου. Η κυπριακή κυκλοφορία μοιάζει πολύ με τη βρετανική σε αυτό το σημείο. Αυτό μπορεί να βοηθήσει σε ενδεχόμενη πρακτική εξέταση.

## Ποιοι δικαιούνται να ανταλλάξουν βρετανική άδεια με κυπριακή;

Δεν μπορεί ο καθένας να κάνει άμεση ανταλλαγή. Υπάρχουν βασικές προϋποθέσεις που πρέπει να πληρούνται. Αν δεν τις πληρείτε όλες, η αίτησή σας μπορεί να απορριφθεί ή να σας ζητηθεί να δώσετε εξετάσεις.

Οι βασικές προϋποθέσεις είναι:

- Να κατέχετε έγκυρη βρετανική άδεια οδήγησης που δεν έχει λήξει.
- Να είστε νόμιμος κάτοικος Κύπρου. Χρειάζεστε έγγραφο που να το αποδεικνύει.
- Να έχετε ιατρικό πιστοποιητικό από εγκεκριμένο γιατρό στην Κύπρο.
- Να είστε σε θέση να παραδώσετε την ή τις αρχικές βρετανικές άδειές σας.

Για τους Βρετανούς που έφτασαν στην Κύπρο πριν από τις 31 Δεκεμβρίου 2020, η κατάσταση μπορεί να είναι διαφορετική. Εκείνη την εποχή, η Βρετανία ήταν ακόμα στη μεταβατική περίοδο του Brexit. Αυτοί οι κάτοικοι πιθανώς έχουν το έγγραφο MEU1 ή ισοδύναμο. Αυτό μπορεί να τους δίνει κάποια πλεονεκτήματα στη διαδικασία. Πάντως, το ΤΟΜ είναι ο μόνος αρμόδιος φορέας για να επιβεβαιώσει τι ισχύει για την περίπτωσή σας.

Αν είστε μόνιμος κάτοικος Κύπρου και έχετε βρετανική άδεια, δικαιούστε να υποβάλετε αίτηση. Η ανταλλαγή γίνεται για τις ίδιες κατηγορίες άδειας που κρατάτε. Αν έχετε άδεια κατηγορίας Β για αυτοκίνητα, θα πάρετε κυπριακή για την ίδια κατηγορία. Για περισσότερες πληροφορίες για την [κατηγορία Β άδεια οδήγησης](/arthra/katigoria-b-adeia-odigisis-kypros) στην Κύπρο, δείτε τον αντίστοιχο οδηγό.

Όσοι δεν είναι νόμιμοι κάτοικοι ή δεν πληρούν τις βασικές προϋποθέσεις δεν μπορούν να κάνουν ανταλλαγή. Σε αυτές τις περιπτώσεις, υπάρχουν άλλες επιλογές. Μπορείτε να διαβάσετε σχετικά παρακάτω στην ενότητα για όσους δεν πληρούν τις προϋποθέσεις.

Ένα σημαντικό σημείο: η βρετανική άδεια πρέπει να είναι σε ισχύ. Δεν γίνεται ανταλλαγή ληγμένης άδειας. Αν η άδειά σας έχει λήξει, πρέπει πρώτα να την ανανεώσετε στη Βρετανία μέσω της DVLA και μετά να επιστρέψετε για την ανταλλαγή. Αυτό μπορεί να πάρει χρόνο, οπότε φροντίστε να ελέγξετε την ημερομηνία λήξης έγκαιρα.

## Ποια έγγραφα χρειάζονται για την ανταλλαγή;

![Αίτηση εγγράφων σε κυπριακή κυβερνητική υπηρεσία, Cyprus government office](/blog/exchange-uk-driving-licence-cyprus/inline-2.jpg)
*Η υποβολή αίτησης στο ΤΟΜ απαιτεί σειρά εγγράφων που πρέπει να ετοιμαστούν έγκαιρα, via Pexels.com*

Η ετοιμασία των σωστών εγγράφων είναι το πιο σημαντικό βήμα. Αν λείπει έστω και ένα, η αίτησή σας μπορεί να καθυστερήσει. Ορισμένα έγγραφα χρειάζονται χρόνο για να τα αποκτήσετε, οπότε ξεκινήστε νωρίς.

Τα βασικά έγγραφα που χρειάζονται είναι:

- Η έγκυρη βρετανική άδεια οδήγησης (πρωτότυπο).
- Επικυρωμένη μετάφραση της βρετανικής άδειας στα ελληνικά.
- Αποδεικτικό νόμιμης κατοικίας στην Κύπρο (π.χ. MEU1 ή ισοδύναμο έγγραφο).
- Ιατρικό πιστοποιητικό από εγκεκριμένο γιατρό στην Κύπρο.
- Έγκυρο διαβατήριο ή ταυτότητα.
- Φωτογραφίες διαβατηρίου (τύπος και αριθμός κατά τις οδηγίες του ΤΟΜ).
- Συμπληρωμένη αίτηση από το ΤΟΜ.

Η μετάφραση της άδειας είναι ένα βήμα που πολλοί ξεχνούν. Δεν αρκεί να πάτε με την αγγλική άδεια μόνο. Χρειάζεται επίσημη μετάφραση στα ελληνικά. Επαληθεύστε με το ΤΟΜ ποια είδη μετάφρασης αποδέχονται, γιατί οι απαιτήσεις μπορεί να αλλάξουν.

Το ιατρικό πιστοποιητικό πρέπει να είναι από γιατρό που αναγνωρίζεται από τις κυπριακές αρχές. Δεν αρκεί βρετανικό ιατρικό πιστοποιητικό. Ο γιατρός θα ελέγξει αν είστε ικανός να οδηγείτε. Ο έλεγχος περιλαμβάνει γενικά την όρασή σας και άλλες βασικές παραμέτρους υγείας.

Το αποδεικτικό κατοικίας είναι εξίσου σημαντικό. Αν είστε κάτοχος του εγγράφου MEU1 ή άλλου πιστοποιητικού εγγραφής, αυτό συνήθως αρκεί. Αν δεν έχετε τέτοιο έγγραφο, ρωτήστε το ΤΟΜ τι άλλο μπορεί να γίνει αποδεκτό. Για όλα όσα αφορούν το [δίπλωμα οδήγησης για ξένους στην Κύπρο](/arthra/diploma-odigisis-gia-ksenous-stin-kypro), υπάρχει ξεχωριστός οδηγός που καλύπτει πολλές περιπτώσεις.

Πριν πάτε στο ΤΟΜ, επικοινωνήστε μαζί τους τηλεφωνικά ή μέσω email. Ζητήστε ενημερωμένη λίστα εγγράφων. Οι απαιτήσεις μπορεί να έχουν αλλάξει από τότε που διαβάσατε αυτό το άρθρο. Καλύτερα να ρωτήσετε μία φορά παραπάνω παρά να κάνετε άσκοπο ταξίδι.

## Πώς γίνεται η διαδικασία βήμα προς βήμα;

Η διαδικασία δεν είναι περίπλοκη, αν ξέρετε τι να κάνετε. Παρακάτω θα βρείτε τα βήματα με τη σωστή σειρά.

1. Ελέγξτε αν η βρετανική άδειά σας είναι σε ισχύ. Αν έχει λήξει, ανανεώστε την πρώτα μέσω της DVLA.
2. Μαζέψτε όλα τα απαραίτητα έγγραφα (δείτε την προηγούμενη ενότητα).
3. Κανονίστε ιατρικό πιστοποιητικό από εγκεκριμένο γιατρό στην Κύπρο.
4. Μεταφράστε την άδειά σας στα ελληνικά από εγκεκριμένο μεταφραστή.
5. Επικοινωνήστε με το ΤΟΜ για να επιβεβαιώσετε τα τρέχοντα έγγραφα και τις ώρες λειτουργίας.
6. Πηγαίνετε στο κοντινότερο γραφείο του ΤΟΜ (Λευκωσία, Λεμεσός, Λάρνακα ή Πάφος).
7. Υποβάλετε την αίτηση και πληρώστε το τέλος.
8. Αναμένετε την επεξεργασία της αίτησής σας.
9. Παραλάβετε την κυπριακή άδεια όταν είναι έτοιμη.

Το ΤΟΜ έχει γραφεία σε τέσσερις πόλεις. Μπορείτε να απευθυνθείτε στο πιο κοντινό σε εσάς. Δεν χρειάζεται να πάτε υποχρεωτικά στη Λευκωσία. Αυτό διευκολύνει πολύ τους κατοίκους άλλων επαρχιών.

Κατά την υποβολή της αίτησης, θα σας ζητηθεί να παραδώσετε την πρωτότυπη βρετανική άδεια. Αυτό είναι υποχρεωτικό. Η κυπριακή πλευρά στέλνει συνήθως την παλιά άδεια πίσω στη βρετανική DVLA. Δεν θα την κρατήσετε εσείς. Γι' αυτό, αν θέλετε αντίγραφο, βγάλτε φωτοτυπία πριν την παραδώσετε.

Μετά την υποβολή, το ΤΟΜ επεξεργάζεται την αίτηση. Ο χρόνος αναμονής διαφέρει. Σε περιόδους μεγάλου φόρτου εργασίας, μπορεί να πάρει περισσότερο. Ρωτήστε κατά την υποβολή για εκτιμώμενο χρόνο παράδοσης.

Η κυπριακή άδεια που θα λάβετε έχει τη μορφή κάρτας, σαν πιστωτική κάρτα. Αυτή είναι η τυπική μορφή των ευρωπαϊκών αδειών. Ισχύει για τις ίδιες κατηγορίες με την παλιά σας βρετανική άδεια. Αν είχατε κατηγορία Β, θα πάρετε κατηγορία Β.

## Χρειάζεται εξέταση για την ανταλλαγή άδειας;

Αυτή είναι η ερώτηση που ανησυχεί τους περισσότερους. Η απάντηση εξαρτάται από την περίπτωσή σας.

Σε πολλές περιπτώσεις, η ανταλλαγή γίνεται χωρίς εξετάσεις. Αν πληρείτε όλες τις προϋποθέσεις και τα έγγραφά σας είναι πλήρη, το ΤΟΜ μπορεί να εκδώσει την κυπριακή άδεια χωρίς να σας ζητήσει να δώσετε τεστ. Ωστόσο, αυτό δεν είναι εγγυημένο για κάθε περίπτωση.

Υπάρχουν περιπτώσεις όπου το ΤΟΜ μπορεί να απαιτήσει:

- Θεωρητική εξέταση (γραπτό τεστ κανόνων κυκλοφορίας).
- Πρακτική εξέταση (τεστ οδήγησης με εξεταστή).
- Και τα δύο.

Πότε είναι πιο πιθανό να ζητηθεί εξέταση; Αν τα έγγραφά σας δεν είναι πλήρη ή αν υπάρχουν αμφιβολίες για την εγκυρότητα της βρετανικής άδειας, το ΤΟΜ μπορεί να απαιτήσει έξτρα βήματα. Ακόμα, αν δεν πληρείτε κάποια βασική προϋπόθεση, μπορεί να σας παραπέμψουν σε εξετάσεις.

Αν χρειαστεί να δώσετε θεωρητική εξέταση, καλό είναι να προετοιμαστείτε καλά. Η εξέταση αφορά τους κυπριακούς κανόνες κυκλοφορίας. Κάποιοι κανόνες μοιάζουν με τους βρετανικούς, αλλά υπάρχουν και διαφορές. Για να μάθετε τι περιλαμβάνει η [εξέταση οδήγησης Κύπρος 2026](/arthra/eksetasi-odigisis-kypros-2026), μπορείτε να διαβάσετε τον αντίστοιχο οδηγό.

Η πρακτική εξέταση στην Κύπρο γίνεται με αυτοκίνητο με χειροκίνητο ή αυτόματο κιβώτιο. Αν η βρετανική σας άδεια ισχύει μόνο για αυτόματο, το ίδιο θα ισχύει και για την κυπριακή. Να το λάβετε αυτό υπόψη.

Η καλύτερη συμβουλή είναι να ρωτήσετε το ΤΟΜ από πριν αν η περίπτωσή σας απαιτεί εξετάσεις. Έτσι δεν θα βρεθείτε μπροστά σε εκπλήξεις. Για έναν [πλήρη οδηγό διπλώματος οδήγησης 2026](/arthra/plires-odigos-diploma-odigisis-kypros), μπορείτε να ενημερωθείτε και για τις εξετάσεις από την αρχή.

## Πόσο κοστίζει και πόσο διαρκεί η διαδικασία;

Το κόστος της ανταλλαγής καθορίζεται από την Κυπριακή Δημοκρατία. Δεν είναι σταθερό και μπορεί να αλλάξει. Γι' αυτό δεν αναφέρουμε συγκεκριμένο ποσό. Για την τρέχουσα τιμή, ρωτήστε το Τμήμα Οδικών Μεταφορών. Στο κόστος αυτό δεν περιλαμβάνονται άλλα έξοδα, όπως η μετάφραση ή το ιατρικό πιστοποιητικό.

Τα έξοδα που πρέπει να υπολογίσετε συνολικά:

- Τέλος αίτησης ανταλλαγής άδειας στο ΤΟΜ.
- Κόστος επικυρωμένης μετάφρασης στα ελληνικά.
- Αμοιβή γιατρού για το ιατρικό πιστοποιητικό.
- Τυχόν έξτρα χρέωση αν απαιτηθούν εξετάσεις.
- Έξοδα μετακίνησης στο γραφείο του ΤΟΜ.

Όσον αφορά τον χρόνο, η διαδικασία μπορεί να πάρει από λίγες εβδομάδες έως αρκετούς μήνες. Εξαρτάται από τον φόρτο εργασίας του ΤΟΜ και αν χρειάζεται κάποια έξτρα επαλήθευση. Αν χρειαστεί επικοινωνία με τη βρετανική DVLA για επαλήθευση της άδειας, αυτό μπορεί να προσθέσει χρόνο.

Η επαλήθευση από τη DVLA είναι κάτι που το ΤΟΜ μπορεί να ζητήσει. Αυτό γίνεται για να επιβεβαιωθεί ότι η βρετανική άδεια είναι αυθεντική και σε ισχύ. Η DVLA στέλνει επιβεβαίωση. Αυτό το βήμα γίνεται συνήθως από το ΤΟΜ, όχι από εσάς. Παρόλα αυτά, μπορεί να επηρεάσει τον συνολικό χρόνο αναμονής.

Μια πρακτική συμβουλή: ξεκινήστε τη διαδικασία νωρίς. Μην περιμένετε να λήξει η βρετανική σας άδεια. Αν η βρετανική άδεια λήξει ενώ η αίτηση εκκρεμεί, μπορεί να δημιουργηθούν προβλήματα. Κάποιοι Βρετανοί στην Κύπρο το ανακάλυψαν αυτό με τον δύσκολο τρόπο.

Αν η βρετανική άδειά σας οδηγεί τον ίδιο τύπο οχήματος με αυτό που οδηγείτε τώρα, μπορείτε γενικά να συνεχίσετε να οδηγείτε με αυτή κατά τη διάρκεια της διαδικασίας. Ωστόσο, συμβουλευτείτε το ΤΟΜ για να επιβεβαιώσετε αν ισχύει κάποιο χρονικό όριο χρήσης βρετανικής άδειας ως κάτοικος Κύπρου.

## Τι γίνεται αν δεν πληροίτε τις προϋποθέσεις για άμεση ανταλλαγή;

Δεν πληρεί ο καθένας τις προϋποθέσεις για άμεση ανταλλαγή. Αυτό δεν σημαίνει ότι δεν μπορείτε να αποκτήσετε κυπριακή άδεια. Σημαίνει ότι η διαδικασία θα είναι διαφορετική.

Αν δεν πληρείτε τις προϋποθέσεις, υπάρχουν τρεις βασικές επιλογές:

- Να δώσετε θεωρητική εξέταση και μετά να ανταλλάξετε.
- Να δώσετε πρακτική εξέταση και μετά να ανταλλάξετε.
- Να ξεκινήσετε από την αρχή τη διαδικασία απόκτησης διπλώματος, όπως κάποιος που δεν έχει ξαναοδηγήσει.

Η τρίτη επιλογή είναι η πιο απαιτητική. Σπάνια εφαρμόζεται σε κατόχους βρετανικής άδειας, αλλά μπορεί να συμβεί σε εξαιρετικές περιπτώσεις. Αν η άδειά σας έχει ακυρωθεί στη Βρετανία για κάποιο λόγο, για παράδειγμα, το ΤΟΜ μπορεί να μην δεχθεί την ανταλλαγή.

Αν σας ζητηθεί να δώσετε εξετάσεις, μην αποθαρρύνεστε. Η διαδικασία είναι γνωστή και έχει γίνει από πολλούς. Μπορείτε να κλείσετε μαθήματα οδήγησης σε αναγνωρισμένη σχολή στην Κύπρο για να προετοιμαστείτε. Για να δείτε πώς έχει [βρετανική άδεια μετά το Brexit](/arthra/vretaniko-diploma-kypros) γενικά, υπάρχει πλήρης οδηγός που καλύπτει και αυτά τα σενάρια.

Μερικές πρακτικές συμβουλές αν βρεθείτε σε αυτή την κατάσταση:

- Ρωτήστε το ΤΟΜ τι ακριβώς λείπει από την αίτησή σας.
- Ζητήστε γραπτή ενημέρωση για τους λόγους απόρριψης.
- Μην δίνετε τα λεφτά σας σε μεσάζοντες που υπόσχονται γρήγορη λύση.
- Αν χρειαστεί εξέταση, κλείστε μαθήματα σε αναγνωρισμένη σχολή.
- Κρατήστε αντίγραφα όλων των εγγράφων που υποβάλλετε.

Αν η κατάστασή σας είναι περίπλοκη, ίσως αξίζει να συμβουλευτείτε έναν δικηγόρο ή έναν σύμβουλο που γνωρίζει τους κυπριακούς κανόνες για τα διπλώματα. Μερικές φορές μια απλή παρεξήγηση μπορεί να καθυστερήσει την αίτηση για μήνες.

Να θυμάστε πάντα ότι οι κανόνες μπορεί να αλλάζουν. Αυτό που ίσχυε πέρυσι μπορεί να μην ισχύει σήμερα. Η καλύτερη πηγή είναι πάντα το ίδιο το ΤΟΜ.

Η ανταλλαγή βρετανικής άδειας με κυπριακή είναι εφικτή για τους περισσότερους Βρετανούς που ζουν νόμιμα στην Κύπρο. Η διαδικασία απαιτεί οργάνωση και τα σωστά έγγραφα. Ξεκινήστε νωρίς, επικοινωνήστε με το ΤΟΜ για επιβεβαίωση και μην αφήνετε την άδειά σας να λήξει ενώ η αίτηση εκκρεμεί. Με τα σωστά βήματα, η διαδικασία γίνεται χωρίς μεγάλα προβλήματα.

## Συχνές Ερωτήσεις

**Μπορώ να οδηγώ στην Κύπρο με βρετανική άδεια ενώ περιμένω την ανταλλαγή;**
Γενικά, οι κάτοχοι έγκυρης βρετανικής άδειας μπορούν να οδηγούν στην Κύπρο για κάποιο χρονικό διάστημα. Ωστόσο, αν είστε μόνιμος κάτοικος, υπάρχουν χρονικά όρια. Επιβεβαιώστε την τρέχουσα κατάσταση με το ΤΟΜ για να αποφύγετε πρόστιμα.

**Τι γίνεται αν η βρετανική άδειά μου έχει λήξει;**
Δεν μπορείτε να κάνετε ανταλλαγή ληγμένης άδειας. Πρέπει πρώτα να ανανεώσετε την άδειά σας μέσω της βρετανικής DVLA. Μόνο αφού έχετε έγκυρη άδεια μπορείτε να υποβάλετε αίτηση στο ΤΟΜ.

**Η κυπριακή άδεια που θα πάρω θα ισχύει και σε άλλες χώρες της ΕΕ;**
Ναι. Η κυπριακή άδεια είναι ευρωπαϊκή άδεια και αναγνωρίζεται σε όλα τα κράτη μέλη της ΕΕ. Έχει την τυπική μορφή κάρτας και ισχύει για τις κατηγορίες που αντιστοιχούν στη βρετανική σας άδεια.

**Πόσο καιρό πρέπει να ζω στην Κύπρο για να κάνω ανταλλαγή;**
Δεν υπάρχει συγκεκριμένος ελάχιστος χρόνος κατοικίας που αναφέρεται ρητά. Αυτό που απαιτείται είναι να έχετε έγκυρο αποδεικτικό νόμιμης κατοικίας στην Κύπρο. Επικοινωνήστε με το ΤΟΜ για λεπτομέρειες σχετικά με την περίπτωσή σας.

**Χάνω τις κατηγορίες άδειας που είχα στη βρετανική μου άδεια;**
Όχι. Η κυπριακή άδεια εκδίδεται για τις ίδιες κατηγορίες με τη βρετανική. Αν είχατε κατηγορία Β για αυτοκίνητα, θα λάβετε κυπριακή κατηγορία Β. Οι κατηγορίες δεν χάνονται κατά την ανταλλαγή.
